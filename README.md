# The ‘recharge my car’ data infrastructure: Documentation

Electric mobility is a key technology for achieving more sustainable transportation and supporting ambitious energy and climate policy objectives. Electric vehicles are highly energy-efficient, and their use enables the integration of renewable energy sources into the transport sector. [recharge-my-car.ch](https://recharge-my-car.ch), the public face of Switzerland’s national data infrastructure for electric mobility, provides real-time information on the availability of electric vehicle charging stations. All data is publicly available as Open Data. 
This documentation provides guidance on all resources and services offered by ‘recharge my car’, including:

* [Map](https://recharge-my-car.ch): Explore the data on an interactive map.
* [How to access the data](https://github.com/SFOE/ichtankestrom_Documentation/blob/main/How%20to%20access%20the%20data.md): Learn about the different ways how to access and use the available Open Data
* [How to query the ich-tanke-strom.ch-API](https://github.com/SFOE/ichtankestrom_Documentation/blob/main/How%20to%20query%20ich%20tanke%20strom.md): Learn how to query the API and integrate the data into your applications.
* [How to connect as a CPO](https://github.com/SFOE/ichtankestrom_Documentation/blob/main/How%20to%20connect%20as%20a%20CPO.md): Find out how Charge Point Operators (CPOs) can connect their infrastructure to the platform for data delivery.
